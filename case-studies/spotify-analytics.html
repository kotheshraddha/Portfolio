Overview

An interactive Spotify Analytics Dashboard designed to explore song, artist, album, and popularity trends through a clean and engaging user interface. The dashboard provides quick insights into music performance and listening patterns.

Purpose

  • Analyze song and artist popularity metrics.
  • Compare album, track, and artist performance.
  • Identify top-performing songs, artists, and trends.
  • Enable data-driven exploration through interactive visuals.

Design perspective

  • Spotify-inspired dark theme for a modern and immersive experience.
  • Intuitive navigation with dedicated Overview, Artists, and Songs pages.
  • Balanced use of KPIs, charts, and tables for high-level and detailed analysis.
  • Focus on clarity, usability, and visual storytelling.

Colour is restrained: one green carries emphasis, everything else stays neutral so the data leads.

Conclusion

This dashboard transforms Spotify music data into an interactive and visually engaging analytics experience, helping users discover trends, top performers, and key performance metrics.
